# EduTrack

A full-stack attendance management application with separate frontend and backend components.

## Structure

- `frontend/` — client application
- `backend/` — server-side API and data handling

## Current focus

The backend includes attendance-related validation and normalization for schools, classes, students, and attendance records.

## Development

Use the dependency configuration inside each of the `frontend/` and `backend/` directories for local installation and startup commands.

## Purpose

EduTrack is intended to provide a structured digital workflow for managing student attendance while keeping frontend and backend responsibilities separated.
